# Kickoff technique & sign-off client — EDAYA

**Public :** CSM EDAYA + référent établissement  
**Durée kickoff :** 45–60 minutes  
**Prérequis :** questionnaire (au moins blocs A–C + H) reçu ; pack Excel en cours ou reçu.

---

## 1. Agenda kickoff (45–60 min)

| Temps | Sujet | Objectif | Sortie |
|------:|-------|----------|--------|
| 0–5 | Accueil & rôles | Présenter CSM, ops, référent client, décisionnaire | Interlocuteurs confirmés |
| 5–12 | Identité école & owner | Valider nom, ville, pays, fuseau, **email propriétaire** | Bloc A–B figés |
| 12–20 | Calendrier | Année, trimestres/semestres, période active, date go-live | Bloc C figé |
| 20–28 | Structure | Template CI vs custom ; niveaux / nb classes | Décision template + plan Excel |
| 28–38 | Périmètre jour 1 | Modules J1 vs P2 (bloc H) | Matrice modules signée oralement |
| 38–48 | Données & Excel | Qui remplit quels fichiers ; deadline J+3 ; règles colonnes | Responsable + date de retour |
| 48–55 | Process EDAYA | « Nous créons les profils → invitations → premier login » | Attentes alignées |
| 55–60 | Formation & suite | Planifier formations + canal support | Dates provisoires |

### Points à trancher explicitement (ne pas laisser flou)

1. Email du **compte propriétaire** (professionnel, stable).
2. Date de **go-live** cible.
3. **Template CI** ou structure custom.
4. Modules **jour 1** (surtout : famille, notes, finance, EDT).
5. Qui livre les Excel et **avant quelle date**.

### Script courte formation (à planifier en fin d’onboarding)

| Audience | Durée | Contenu |
|----------|------:|---------|
| Direction / owner | 30 min | Navigation, permissions, invitations, vue d’ensemble |
| Secrétariat | 45 min | Élèves, classes, imports, absences / scolarité selon J1 |
| Enseignants (optionnel) | 30 min | Portail enseignant, notes / EDT si J1 |
| Famille (optionnel) | 15 min | Premier login tuteur (si portail J1) |

## 2. Checklist sign-off client (avant envoi massif des invitations)

À faire remplir / cocher par le référent projet après provisionnement et avant go-live large.

### Identité & accès

- [ ] Le nom de l’établissement affiché dans EDAYA est correct
- [ ] Le compte propriétaire s’est connecté avec succès
- [ ] Le fuseau horaire et la ville / pays sont corrects

### Calendrier

- [ ] L’année scolaire affichée est correcte
- [ ] Les périodes (libellés + dates) sont correctes
- [ ] La période active au démarrage est la bonne

### Structure & effectifs

- [ ] Les niveaux et classes correspondent à la réalité (noms exacts)
- [ ] L’effectif par classe est acceptable (écarts listés ci-dessous si besoin)
- [ ] Les matières du jour 1 sont correctes (ou report volontaire en P2)

### Profils

- [ ] Le personnel jour 1 est présent avec les bons rôles
- [ ] Les enseignants jour 1 sont présents (si applicable)
- [ ] Les tuteurs / élèves à inviter sont prêts (si applicable)

### Périmètre

- [ ] Nous confirmons les modules **jour 1** suivants : _______________________
- [ ] Nous acceptons que le reste soit traité en **phase 2**
- [ ] Nous autorisons EDAYA à envoyer les invitations aux adresses fournies

### Écarts connus (optionnel)

| Écart | Décision |
|-------|----------|
| | ☐ Corriger avant go-live ☐ Accepter ☐ Reporter P2 |

## 3. Message type d’envoi du kit (CSM → client)

> Objet : EDAYA — dossier d’ouverture de votre établissement  
>
> Bonjour,  
>
> Pour préparer votre espace EDAYA, merci de nous retourner sous **3 jours ouvrés** :  
> 1. Le questionnaire d’ouverture (document joint / lien)  
> 2. Les fichiers Excel du pack (modèles joints) — au minimum personnel + élèves si usage immédiat  
>
> Nous organiserons ensuite un **kickoff de 45–60 minutes**, puis notre équipe créera l’école et les profils. Vous recevrez des **invitations par email** pour votre première connexion.  
>
> Cordialement,  
> L’équipe EDAYA
